# Beginner Track — Week 2: Python Syntax, Variables, Data Types & Input/Output

Welcome to my Week 2 submission for the AI-Native Python Programming Internship! This folder contains five mini-programs built from scratch to practice fundamental Python concepts, user input handling, and basic data types.

## Included Mini-Programs

 **Profile Card (`profile_card.py`)**
   **Description:** Collects basic user details (name, age, city, employment status) and prints them out in a neatly formatted card using f-strings.
 **Age Calculator (`age_calculator.py`)**
   **Description:** Prompts the user for their birth year, converts the input to an integer, and calculates their current age.
 **Unit Converter (`unit_converter.py`)**
   **Description:** Takes a distance value in kilometers from the user, converts it to a float, and calculates the equivalent in miles.
 **Receipt Total Calculator (`receipt_total.py`)**
   **Description:** Calculates the subtotal of multiple items, applies an inputted vat rate, and outputs a complete receipt summary.
 **Simple Interest Calculator (`simple_interest.py`)**
   **Description:** Prompts the user for Principal amount, Rate in percentage, and Time period, then computes and displays the simple interest.
